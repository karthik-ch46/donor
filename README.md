# Blood Donor Website

## Project Title

Blood Donor Management and Search System

## Description

This project is a Flask-based blood donor website.

Users can:

1. Login using mobile number.
2. Complete their profile.
3. Register as a blood donor.
4. Provide blood group and location.
5. Search donors according to required blood group.
6. View matching donor information.
7. View donor location.
8. Logout.

## Technologies

- Python
- Flask
- SQLite
- HTML
- CSS
- JavaScript

## Run Locally

Install the required packages:

pip install -r requirements.txt

Run the application:

python app.py

Open the website in a browser.

## Project Flow

Login
→ Profile
→ Donor Registration
→ Blood Group Search
→ Matching Donors
→ Logout
